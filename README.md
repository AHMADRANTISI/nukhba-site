# قِمّة — حرّاس الكونكر

منظومة لتنظيم لاعبي ببجي المحترفين الموثّقين ("حرّاس القمة") وحجزهم لرفع الحسابات:
كونكر كلاسيك، كونكر ألتميت، مترو رويال. كل حارس له عدد محدود من المقاعد في الموسم (8 افتراضياً).

## التشغيل

```bash
npm install
cp .env.example .env   # ثم املأ CRED_KEY و ADMIN_PASSWORD
npm run setup          # ينشئ قاعدة البيانات ويضيف الأدمن والموسم ولاعبين تجريبيين
npm run dev            # http://localhost:3400
```

لتوليد `CRED_KEY`:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

## كيف يعمل

- **الحرّاس**: الأدمن يضيفهم من `/admin/players` (صورة، جهاز، سنوات اللعب، عدد الحسابات المنجزة، تيك توك ولقطاته، السعر ومدة الإنجاز لكل نوع رانك).
  لا يُنشر الحارس إلا بعد اكتمال سجل الثقة الأربعة (هوية، سجل نظيف، لعب مُراجَع، ميثاق موقّع).
- **المقاعد**: تُحسب على الموسم النشط (`/admin/settings`). الحجز غير المدفوع يحجز المقعد 24 ساعة فقط.
- **الدفع**: يدوي — العميل يحوّل ويرفع صورة الإثبات، والأدمن يؤكد.
- **الأمان**: بيانات دخول حساب العميل مشفّرة AES-256-GCM، تظهر للأدمن فقط، وتُمسح تلقائياً عند الإنجاز أو الإلغاء.
  صور الإثبات محفوظة في `storage/` ولا يراها إلا صاحب الحجز والأدمن.

## قبل الإطلاق

- احذف أو عدّل اللاعبين التجريبيين، وضع بيانات طرق الدفع الحقيقية ورقم واتساب.
- غيّر كلمة مرور الأدمن، واستخدم قاعدة بيانات Postgres إن كان الاستضافة لا تدعم ملفات SQLite دائمة.
